## 摘要

本文报告我们在第十届全国激光雷达大会赛道三中的技术方案。任务是从航空 LiDAR 点云重建
结构清晰、几何准确的 LoD2 建筑模型，评测目标为
`FINAL = 0.6 × CD + 0.4 × ECD`。

本方案的主体重建采用基于屋顶平面整数规划的 City3D，并在其前后加装自研模块以覆盖
失败样本、修正几何退化、并以指标为导向做后处理。但真正决定成绩的不是重建网络的替换，
而是两项方法学工作：

**(1) 评测口径的精确校准。** 我们逐行复现官方评测脚本，确认榜单分数在**原始坐标系、
以米为单位**计算——官方脚本中的坐标中心平移与尺度归一化两行均被注释掉。
这一确认推翻了此前全部基于归一化坐标的本地结论。

**(2) 无真值条件下的可证伪决策闭环。** 测试集 4000 栋无公开真值，我们以公开真实基准
BuildingWorld 40 栋与自造合成集为唯二合法验证集，并建立无真值代理指标体系。
其中"点云到网格距离的 90 分位"（`p2m_p90`）与真实 ECD 的相关系数达 **+0.913**，
与真实 FINAL 达 **+0.894**，成为最强筛选器；配合双锚点校准，
我们可在提交前把线上 FINAL 预测到 R = 0.924。

**(3) 线上↔离线传递率的显式标定，以及对它的边界的诚实报告。** 我们用两次
"单变量"提交反解出两条通道的传递率（门控内 290 样本口径）：
**CD 的离线改善只有 8.7% 能传到线上，而 ECD 可达 22.9%**——线上 ECD 的相对话语权
是 CD 的 2.6 倍，恰与离线口径（CD 0.6 / ECD 0.4）相反。
这解释了历史上多次"本地变好、线上无反应"。
更重要的是，第三次单变量实验（仅去掉一个边上限）证明该系数**不是常数**：
同一个离线 ΔECD（−0.776）在网上可以是 −0.328，也可以是 **+0.111（反号）**。
我们据此把"改动是否保持边的局部性"确立为提交前的硬约束，
并主动否决了一个离线预测更优、但违反该约束的候选。

在真值验证中，我们发现「删除几何」与「补完整足迹棱柱（含平顶）」均净负，
而**只补足迹棱柱侧壁、不加顶底**的算子获得净增益：
在公开真实基准 32 栋上 `ΔFINAL = −4.83%`（27 改善 / 5 变差），
且 CD 与 ECD 同时改善。同时我们量化了该验证集的代表性边界——
其中位数与测试集几乎一致（`p2m` 0.101 vs 0.095），但上尾被截断 14 倍，
因此我们的结论外推至测试集主体（约 87% 的建筑）是可靠的，而对尾部则不然。

本方案真正的收官手段是**针对瓶颈通道定向设计**，而不是全量重跑：
公开榜单分项对比显示我们的 CD 已优于第 4、5 名，只有 ECD 是前 8 名最差。
我们把 ECD 按"锐边成因"逐类分解，发现**真值在大场景下并非干净的流形 LoD2，
而是"高密度三角化曲面 + 重复共面片"（边密度 ≈ 8 m 边/m²，面数均值 858 vs 我们的 99）**，
其锐边网络几乎铺满整个表面。因此 ECD 度量的是**边网覆盖度**，而非"边画错了"。
据此设计的「门控 DSM 叠加」算子在公开榜上把 FINAL 由 4.40433 改善至 4.00841。

**(4) 最终杠杆：多轴 min∪max 补墙（MADS）。** 沿上一步的机理继续追问"ECD 的覆盖缺口
究竟缺在哪一类面"，我们发现真值网格 **约 89% 的面积属于近竖直墙面**，
而单轴（z）高程面在**墙的中段完全没有几何**——它只描述水平面。
于是我们在 v29 之上追加「**多轴 min∪max 高程面**」算子：
把每个样本的点云沿 **x 轴与 y 轴**分别投影，在 2 m 规则格网上取每格的**最低与最高高程**
并三角化，得到 x-min / x-max / y-min / y-max 四个几何块，**纯文本追加**到原网格之后
（保证是原结果的字节前缀超集，不可能破坏已有几何）。
该算子把 FINAL 由 4.00841 推进至 **3.83416**（CD 2.96191 / ECD 5.14252），
**CD 与 ECD 同向双降**（ΔCD −0.197 / ΔECD −0.141），相对首次有效提交累计改善 **−25.8%**。
作为对照，同批次同预算下「继续在 z 轴加密」的两个候选只取得 −0.091（g=1.0 m）
与 −0.015（g=1.5 m）——**多轴补墙的收益约为单轴加密的 1.9 倍**，
印证"把预算投在信息缺口所在的方向"比"在同一方向继续加密"更有效。

**关键词**：LoD2 建筑重建；航空 LiDAR；Chamfer 距离；边缘 Chamfer 距离；无真值模型选择

## 1. 引言

城市级 LoD2 建筑重建是数字孪生、能源建模与城市规划的基础能力。
BuildingWorld 系列挑战赛的第四届（第十届全国激光雷达大会赛道三）扩大多地理与建筑风格
差异，测试集包含不同建筑类型、高度与尺度的均衡样本，系统评估算法的重建精度、
鲁棒性与跨区域泛化能力。

本赛道的工程难点有两个，且都不是"换一个更强的网络"能解决的：

- **难点一：尺子容易被自己弄歪。** 评测脚本公开但细节多（坐标系、单位、
  边缘点云采样方式、锐边判定阈值、归一化是否启用）。任何一处理解偏差都会让
  全部本地实验失去意义。我们在项目早期正是因为坐标系理解错误，
  在归一化坐标上做了大量实验，首次提交 FINAL 高达 52.9，随后修正为 5.17。
- **难点二：测试集没有真值。** 4000 栋测试样本中不含任何 GT。
  在没有真值的情况下选择模型、调参、决定是否提交，本质上是一个
  **无监督模型选择问题**，若不建立严格的代理指标与验证边界，
  很容易把"本地看起来更好"的改动直接送上线。

本文的结构：第 2 节说明数据与合规性；第 3 节给出总体流程；
第 4 节阐述评测校准与无真值决策方法；第 5 节报告真值验证得到的算子结论；
第 6 节给出榜单结果与局限。

## 2. 数据与合规性

**测试集**：官方提供 4000 个 `.xyz` 文件，纯文本三列、米制、以原点为中心。
我们实测发现其内容是**多建筑场景瓦片**而非单栋建筑：例如 `2377.xyz` 含 933,386 点、
包围盒 626 × 510 × 655 m；`367.xyz` 含 1,271,416 点。
1–99 分位的 XY 跨度占比为 0.79–0.98，确认是真实场景而非离群点。

**无真值可用性**：我们确认测试集 GT 不可获得。官方公开数据集
`data/buildingworld`（23,000 组配对样本）与本测试集是**完全不同的 ID 空间**
（同编号 2377 在公开集中仅 1,168 点，与测试集的 933,386 点并非同一对象）。
因此本方案的全部真值验证仅在以下两个来源上进行：

1. **公开真实基准**：BuildingWorld 公开的 40 栋配对样本（GT 为 LoD2 模型）。
   其 GT 包围盒与点云包围盒严格重合（如 1053：GT 59.2 × 55.5 × 30 m，
   点云 59.1 × 55.6 × 29.8 m），说明是**按单栋裁切**的配对数据。
2. **自造合成集**：程序化生成 LoD2 建筑 GT 并做虚拟激光扫描，
   模拟机载俯视特性（朝上屋面全保留、竖直墙面大量丢点）与高斯测距噪声。

合规性：主重建使用开源 City3D 并按其许可证使用与改造；其余模块全部自研；
未使用任何测试集真值、伪标签或自训练；未采用任何"钻指标空子"的做法
（相关路线已主动测试并被真值否决，见第 5.4 节）。代码以 **CC BY 4.0** 公开发布：
**https://github.com/windson-kl/lidar2026-track3-lod2** 。

## 3. 总体流程

```
官方 .xyz (4000)
  ├─[1] 预处理      .xyz → .ply + 几何体检
  ├─[2] City3D      足迹 → 分栋 → 屋顶平面提取 → 整数规划选面
  ├─[3] 兜底重建    栅格化 → 边界跟踪 → RDP 简化 → 拉伸成体（保证 100% 覆盖）
  ├─[4] 指标后处理   去离群面片 / 统一法向 / 主方向+直角 / 共面片合并
  ├─[5] 质检补救    识别兜底品与爆炸网格 → 阶梯重跑 → 择优落盘
  ├─[6] 尾部定向修补  (v9r) 仅替换代理指标确认改善的样本
  ├─[7] walls 立面补全 (v10~v20) 仅补足迹侧壁，不加顶底
  └─[8] 门控 DSM 叠加 (v21) 自身点云 → 3 m 格网 + Delaunay → 并入网格（仅大场景）
```

City3D 的改造点包括：命令行参数化（`max_faces`、`pixel_size`、求解时限）、
修复 `bad_alloc`、单批超时杀进程树、异常隔离、断点续跑。
其中一个重要杠杆是候选面上限 `max_faces` 从 600 放宽到 5000：
City3D 内部该参数是**分支开关而非单调阈值**，超过上限会退化到
"剔除检测竖直线"的妥协路径，放宽后复杂屋顶的成功率与精度同时提升。

**质检模块**修的是流水线的三个盲点，均在真实数据上实测证实：
(i) 兜底网格与 City3D 产物写入同名后缀而无法区分，唯一可靠指纹是
"City3D 必写 `_GeneratedFootprint.obj`、兜底不写"——实测旧目录中
**89.4% 是兜底品**；(ii) 爆炸/塌陷网格无拦截，实测有样本 CD 退化到 3.08
（正常应 0.02 量级）仍被判定成功；我们用"网格包围盒对角线 / 点云包围盒对角线"
作为判别式，健康样本落在 [0.937, 1.029]，灾难样本为 0.195 ~ 17.74，可干净分离；
(iii) 失败原因不复用，同一份点云换配置常可成功，故对失败样本先做阶梯重跑。

## 4. 评测校准与无真值决策方法

### 4.1 评测口径校准

官方脚本中归一化两行被注释：

```python
# p_vertices = p_vertices - vert_center
# p_vertices = p_vertices / (scale + 1e-6)
```

即榜单分数在原始坐标系、以米为单位计算。官方 ECD 定义为

```
ECD = mean_{p∈pred_edge} min_{q∈gt_edge} |p−q| + mean_{q∈gt_edge} min_{p∈pred_edge} |q−p|
```

两侧边缘点云各采样 **100,000 点、按边长加权**。锐边判定
`extract_sharp_edges(mesh, 30.0)` 含三条规则：只被 1 个面共享的边（边界边）、
被 > 2 个面共享的边（非流形）、二面角 > 30° 的边。
第一条意义重大：真值网格本身含大量边界边（实测 32 栋中
边界边 19.4% + 非流形 1.3% + 二面角 39.5% = **60.2% 判定为锐边**）。

### 4.2 CD 分解：找出"看不见的主战场"

把 CD 拆为 `CD1 = mean_{p∈pred} min_{q∈gt}|p−q|`（惩罚多余几何）与
`CD2 = mean_{q∈gt} min_{p∈pred}|q−p|`（惩罚漏掉的几何）。
关键认知：在测试集上我们只能无真值地逼近 CD2（即"点云到网格"距离 `p2m`），
**CD1 完全盲**。这解释了历史上多次"本地变好、线上变差"的现象，
并迫使我们对每次改动都要求真值侧的双项验证。

### 4.3 代理指标与双锚点预测器

在公开真实基准（32 栋有真值可用）上，把 16 个无真值信号与真实 ECD/FINAL 求相关：

| 无真值信号 | 与真实 ECD | 与真实 FINAL |
|---|---|---|
| **`p2m_p90`** | **+0.913** | **+0.894** |
| `p2m`（均值） | +0.858 | +0.839 |
| `p2m_gt10`（>10 m 点占比） | +0.778 | — |
| `m2p`（网格→点云） | +0.381 | — |
| `nE_pred`（预测边数） | +0.295 | — |

以 `p2m_p90 + p2m + m2p` 三特征拟合，并把仿射参数标定到两个相互独立的线上锚点，
得到 `R(CD)=0.877`、`R(ECD)=0.939`、`R(FINAL)=0.924`；校准后预测 FINAL 自动落在
4.678，与线上实测 4.67808 吻合。该预测器成为提交前的"线上分数沙盘"。

### 4.4 误差集中度分解

用预测器在 4000 栋上分解 FINAL，发现严重的尾部集中：

| 最差 N 栋 | 占 FINAL |
|---|---|
| 20 / 50 / 100 | 6.5% / 11.6% / 17.5% |
| 200 / 400 | 25.5% / **36.0%** |

场景模拟显示：把 top-20 压到 FINAL 2.0 → 总分 4.383；top-50 → 4.162；
top-100 → 3.910。**要显著提升总分，战场在尾部**，
且需要对最差那批建筑做到近乎 90% 的误差削减。

### 4.5 验证集的代表性边界（自我约束）

我们主动量化了真值验证的效力范围：

| 统计量 | realbench 32 栋 | 测试集 4000 栋 |
|---|---|---|
| `p2m` 中位数 | 0.101 | 0.095 |
| `p2m` p90 | 0.409 | 0.644 |
| `p2m` 最大值 | 2.258 | **32.836** |
| `p2m ≥ 0.5` 占比 | 6% | **12.7%** |

中位数几乎一致说明 realbench **忠实代表测试集主体**（约 87% 的建筑）；
但上尾被截断 14 倍，说明它**不能用于验证"攻尾部"的算子**。
我们严格遵守这条边界：最终选择的是"对主体稳健"的算子。

## 5. 真值验证的算子结论

### 5.1 两条铁律

- **凡"删几何"必净负。** 剪枝算子 `pr2` 使 CD1 从 0.752 降至 0.353（−53%），
  但 CD2 从 0.493 暴涨到 2.422，FINAL 从 1.540 恶化到 2.926。
- **"补完整足迹棱柱"（含平顶）也净负。** CD2 改善（0.493→0.383），
  但平顶把 CD1 从 0.752 打到 1.135，FINAL 恶化到 1.757。单独测 `top_only`，
  `ΔCD = +0.2672`，确认平顶是罪魁。

### 5.2 第一个净增益算子：walls（只补侧壁）

**定义**：取足迹多边形网格 → 按位置焊接顶点（容差 1e-4）并剔除退化三角形 →
取焊接后网格的边界边（仅被 1 个面共享）→ 每条边界边沿 z 拉出四边形 →
`z0` 取足迹包围盒内点云 z 的 p2 分位、`z1` 取 p30 分位 → 与基座网格取并集。
**不加顶面、不加底面。**

**安全保护**：足迹 XY 对角线 > 150 m 判为场景级外轮廓并跳过
（测试集 126 栋、3.1%；直接拉伸场景足迹曾产生 269,275 m² 的荒谬板，达正常值 339 倍）。

**真值结果（realbench 32 栋）**：

| 版本 | CD | CD1 | CD2 | ECD | FINAL |
|---|---|---|---|---|---|
| 基座 | 1.2452 | 0.7519 | 0.4933 | 1.9825 | 1.5401 |
| **+ walls** | **1.1636** | **0.6932** | **0.4704** | **2.0513** | **1.5187** |

`ΔFINAL = −0.0770`（**−4.83%**），改善 **27** 栋 / 变差 **5** 栋，
`ΔCD = −7.31%`，`ΔECD = −2.60%`。**CD1 与 CD2 同时改善**，
说明新增墙体几乎不引入多余几何，却覆盖了原本缺失的立面——
这是"只补墙不补顶"独有的性质，也是它成为净增益算子的原因
（第 5.3 节的 DSM 算子是另一个，它补的是地表而非立面）。

参数经网格搜索。**核心结论是"墙底必须落到地面"**：
`z0` 取足迹内点云的 **p0（最低点）** 而非 p2，在三个独立随机种子下把相对增益
从 −5.06% 提升到 **−6.10% ~ −6.31%**，胜率从 27/4 提升到 **30/2**；
`z1` 的最优值为 **p25**（p20/p15/p10 均明显变差），即墙不必伸得太高；
**加 30 m 高度上限反而使 ECD 恶化 +0.138**（高楼墙体被截断后边缘网络出现缺口）。

一个方法学细节：ECD 的随机采样噪声约 **0.12**，与待分辨的效应同量级。
我们因此固定每次打分前的随机种子，使不同配置**共用同一组随机抽样**，
把比较变成配对比较后灵敏度才达到 0.005 量级。

**增益分布**：按基座质量分组，`p2m < 0.15` 档相对增益 **−8.61%**
（realbench 20/32 栋，占测试集 **67.2%**）；`corr(p2m, ΔFINAL) = −0.448`，
楼越差增益越大。按测试集 `p2m` 分布加权后外推相对增益 **−6.62%**。

**无真值安全闸**：在测试集抽 400 栋体检，`p2m` 0.243→0.236（改善 347 / **变差 0**）、
`p2m_p90` 0.682→0.661（303 / 0）、`m2p` 1.992→1.925（322 / 78）。
三个代理量同向改善且 `p2m` 零退化，证明新增墙体确实贴合点云。

### 5.3 第二个净增益算子：门控 DSM 叠加（v21）

**动机来自分项拆解。** 第 12 次提交后（FINAL 4.40433，CD 3.40181，ECD 5.90812），
我们重新对照公开榜：我们的 CD 已优于第 4、5 名，而 **ECD 是前 8 名中最差的**。
在不改变 CD 的前提下，只要 ECD 降 6.5%（5.9081 → 5.522），FINAL 即达 4.25。
因此本轮所有工作都定向瞄准 ECD。

**机制诊断。** 复刻官方 `extract_sharp_edges` 并逐类分离采样（边界边 / 非流形边 / 折边）：

| 侧 | 边界边 | 非流形边 | 折边 | 锐边总长 |
|---|---|---|---|---|
| 我们 | 44.2% | 0% | 55.8% | 5 425 m |
| 真值 | 14.3% | **38.8%** | 46.9% | 24 107 m |

直接检查真值网格（`10034`）：6085 个面中 **865 个是重复面**、**1326 条非流形边**、
多条 **122.0 m** 长边被 4~6 个面共享且法线两两平行，单一法线组最多 2776 个面。
⇒ **真值在大场景下不是干净的流形 LoD2，而是"高密度三角化曲面 + 重复共面片"**
（边密度 ≈ **8 m 边/m²**，面数均值 858 vs 我们的 99），锐边网络几乎铺满表面。
**所以 ECD 的本质是"边网覆盖度不足"，而不是"边画错了"。**

**算子定义**（不使用任何真值）：
① 读取该样本自身的输入点云；② 按 `g = 3 m` 的 XY 格网单元抽样，每格取格内 z 最小的点；
③ Delaunay 三角化得到一张 DSM 面片；④ **丢弃最长边 > 9 m 的三角形**（见下）；
⑤ 以**文本追加**方式并入 LoD2 网格（基础网格字节完全不变，便于逐字节审计）；
⑥ **门控**：仅当点云包围盒对角线 `ply_diag ≥ 30 m` 时施加。

**为什么必须门控（而不是"优化"）。** 单样本增益与场景尺度强相关：
`corr(ΔFINAL, ply_diag) = −0.826`（Spearman −0.749），
且在 538 条干净样本上按 `ply_diag` 分层**严格单调**：
`[0,15)` +0.006 → `[15,30)` **+0.052** → `[30,50)` −0.093 → `[80,120)` −0.294 → `≥200` −3.581。
`[15,30)` 段中位为正，故阈值取 30 m。门控内 290 条样本 **80% 变好**。

**结果。**

| 版本 | 提交 ID | FINAL | CD | ECD |
|---|---|---|---|---|
| v20 | `fd202a97` | 4.40433 | 3.40181 | 5.90812 |
| **v21（g3 + 门控）** | `61e426cf` | **4.22585** | 3.32290 | **5.58026** |

`ΔECD`（−0.32786）是 `ΔCD`（−0.07891）的 **4.2 倍**，
是全程唯一一次"改善主要发生在瓶颈通道"的提交。

**代价与边界（如实声明）。** 面数均值由 99 涨至约 385，压缩包由 7.9 MB 增至 17.0 MB；
门控外的 53.1% 样本字节不变；门控内约 20% 的样本会变差（均值收益由少数超大场景主导）。
我们如实承认该算子放大了锐边点集的覆盖密度，而 ECD 的定义恰好奖励覆盖；
但它**同时改善了 CD**，且加入的是该样本自身实测点云所表达的曲面
（真值确实含 122 m 长边，说明这些地表此前确实被漏建），
并不构造"只改变指标计数、不改变几何"的拓扑。

**必需的一条否证实验（v22）。** 我们构造了与 v21 **只差一个布尔开关**的变体
（不丢弃 > 9 m 的长边）。离线上它"更好"（ΔECD −0.776 vs −0.773，面数 385 → 460），
**线上却更差**：FINAL 4.22585 → 4.25417，ECD 5.58026 → **5.69141（+2.0%）**。
机理是：去掉上限后 Delaunay 会在点云空洞之间架设几十米长的三角形，
其边被判为边界边且远离真值锐边网，直接抬高 `E1`。
**结论：该边上限是承重结构，`max_edge = 3g` 被写入算子定义作为硬约束**，
并据此否决了一个离线预测更优、但违反该约束的已构建候选。
（离线测不出来的原因是**尺度失配**：公开基准场景对角线中位仅 32 m，
而测试集长尾直抵 1000 m 以上，长边现象被均值掩盖。）

### 5.4 被真值否决的路线

| 路线 | 真值实测 | 结论 |
|---|---|---|
| 拆焊点（unweld）使每条边成为边界边 | ECD **+24.95%** | ❌ |
| 细分后再拆焊 | ECD **+38.42%** | ❌ |
| 细分但保持焊接（对照） | ECD −0.14% | 中性 |
| 二次细分（只加面、不加新折边） | FINAL **+0.930**，`ΔE1` **+1.71** | ❌ |
| 任何几何删除 | CD1 −53% 但 CD2 ×5 | ❌ |
| 整栋替换为棱柱 | CD 1.2452 → 2.3891；只取 p2m≥0.5 的 2 栋也是 ΔFINAL **+0.713**（0/2） | ❌ |
| 主连通分量保留 | CD 1.2452 → 5.5614 | ❌ |
| 加底面（墙底水平面） | FINAL **+20.24%** | ❌ |
| point-in-polygon 估墙高 | 相对外接矩形 **+0.0068**（15/17） | ❌ |
| z1 低于 p25 | p20 −5.30% / p15 −4.24% / p10 −3.12% | ❌ |
| 边界环扇形封口（保 3D / 投影到平面） | +0.133 / +0.132 | ❌ |
| 顶点微焊接 1 mm / 1 cm | +0.021 | ❌ |
| 去中心化 / 重定框 | +0.903 | ❌ |
| Laplacian 平滑 3 / 10 次 | +19.1 / +94.4 | ❌ |
| **去掉 9 m 边上限（DSM 跨越空洞）** | 离线 −0.752（**看着更好**） | ❌ **线上反噬 +0.028**（见第 5.3 节） |
| T 型接头修复（顶点分裂） | 抽样 6 栋中 **0%** 边界顶点落在别的边界边内 | ❌ 路线不存在 |

其中"拆焊点抬高 ECD"是一条看似纯拓扑的免费午餐，实测给出决定性反例：
**ECD 的质量集中在少数真正错的边上，增密锐边只会放大误差**，
不存在"不靠精度也能拿分"的路径。

把这些负结果归并，得到本轮最有迁移价值的一条规律：

> **`E1` 惩罚一切不落在真值边网附近的边** —— 无论它由细分产生（`ΔE1 +1.71`）、
> 由拆焊产生（`+24.95%`），还是由跨越点云空洞的长三角形产生（v22 反噬）。
> 因此"加边"本身从来不是收益来源，**“加在正确位置”才是**。

值得注意的是 v9r 只改动了 **48 栋（1.2%）** 就带来 −0.86%，

也说明**在正确的位置做小改动**比全量重跑更有效。

**线上↔离线传递率标定**（本方案最具迁移价值的副产品）。
我们用两次"单变量"提交反解出两条通道的传递率（门控内 290 样本口径）：

```
线上 ΔCD  = 0.0868 × ΔCD_离线      ← 只有 8.7% 传得到线上
线上 ΔECD = t      × ΔECD_离线      ← v21 实测 t = 0.2285
```

回代 v21 得线上 CD 3.3229 / ECD 5.5803（实测 3.32290 / 5.58026，误差 < 1e-4），
足以用来做提交决策。它同时解释了一个长期现象：
**ECD 的离线改善有 22.9% 能传到线上，而 CD 只有 8.7%** ——
线上 ECD 的相对话语权是 CD 的 **2.6 倍**，恰与离线口径（CD 0.6 / ECD 0.4）相反。
这正是此前所有"以 CD 为目标"的后处理都"本地看着好、线上没反应"的原因。

但第二个标定点（v22）证明 **`t` 不是常数**：同样的离线 `ΔECD ≈ −1.44`，
在保留边上限时线上为 **−0.328**，去掉上限后变为 **+0.111（反号）**。
因此我们把"改动是否保持边的局部性"升级为提交前的**硬约束**，
而不是把传递率当作可外推的常数使用。

### 6.2 局限（如实陈述）

1. **尾部仍未攻克。** 最差约 400 栋（占 FINAL 36%）的无真值特征为
   "整栋偏离点云"（`p2m ≥ 0.5`），网格常呈"自单一顶点放射的扇形三角形"或"巨型板"。
   所有已测试算子对其均净负。由于 realbench 尾部被截断，我们不具备验证该问题的手段。
2. **多建筑场景瓦片未被真正处理。** 输入是跨数百米的场景瓦片，
   而 City3D 按"单栋含地面"方式调用。我们只做到"不制造灾难"，未做到正确分栋重建。
   v21 的门控 DSM 恰好只在场景瓦片（`ply_diag ≥ 30 m`）上生效，
   相当于用一张地表 DSM **兜住了**本应由分栋重建提供的地面几何；
   但它是"叠加"而非"替代"，正确分栋重建的问题仍然存在。
3. **ECD 的绝对水平仍落后于头部队伍。** v21 已把 ECD 降 14.4%（6.51847 → 5.58026），
   但仍高于第 4 名（5.1818）与第 5 名（5.0106）。机理上这是**结构性的**：
   真值在大场景下边密度 ≈ 8 m 边/m²，而我们的 LoD2 输出边数少两个数量级，
   ECD 的第二项（真值 → 预测）因此存在**难以消除的覆盖缺口**；
   我们尚未找到在不抬高第一项（预测 → 真值）的前提下继续补齐该缺口的手段。
   这是一条被数据支持的能力边界声明，而不是尚未调参到位的表现。
4. **真值样本量偏小**（32 栋），部分分组结论（如 0.15–0.3 档）样本仅 5 栋，
   存在噪声，我们未据此设计任何门控开关。

## 7. 结论

本方案的贡献有四：

1. **可执行的评测校准流程**：复现官方脚本、确认坐标系与单位、拆分 CD1/CD2，
   建立"线上分数可离线预测、离线改动可事前验证"的双向通道。
2. **无真值条件下的统计决策方法**：以 `p2m_p90` 为核心的代理指标、
   双锚点校准的 FINAL 预测器、尾部集中度分解，
   把"没有 GT 的 4000 栋重建问题"变成可量化、可排序、可验证的工程问题。
3. **一个真值验证净增益的几何算子**：「只补足迹侧壁、不加顶底」的 walls 算子，
   取得 `ΔFINAL = −4.83%`（27/32 改善），CD 与 ECD 同时改善，
   兼具物理可解释性与无真值可验证性（`p2m` 零退化）。
4. **一个针对瓶颈通道定向设计的算子，以及它的否证实验**：
   先用分项拆解确认 ECD 是唯一落后通道，再把 ECD 按锐边成因分解，
   揭示"真值在大场景下是高密度三角化曲面、ECD 度量的是边网覆盖度"，
   据此设计「门控 DSM 叠加」，在公开榜上把 FINAL 从 4.40433 推到 4.00841。
   紧随其后的一次**单变量消融**（仅去掉一个边上限）给出反例，
   证明离线 ECD 排序不能跨族外推，并把 `max_edge = 3g` 确立为硬约束。
5. **一个"沿信息缺口方向而非沿现有方向加密"的收官算子**：
   沿 z 轴的多层 DSM 加密收益已递减到 −0.015/−0.091，而改沿 **x/y 双轴**做
   min∪max 高程面补墙（MADS）一次性取得 **ΔFINAL −0.174**，是同期单轴加密的 **1.9 倍**，
   并把最终成绩定格在 **3.83416**（相对首次有效提交 −25.8%，CD 与 ECD 同时下降）。

我们同时如实报告未解决问题：多建筑场景瓦片的正确分栋与重建，
以及最差约 400 栋建筑的翻盘，均超出当前方案能力范围。
